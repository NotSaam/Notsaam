## 🚀 Proyecto destacado — FLK0S

**Cybersecurity Operations Platform** · una plataforma que unifica Blue Team, Red Team, agentes de IA
y reporting bajo un único inicio de sesión.

<a href="https://github.com/NotSaam/FLK0S-Ecosystem">
  <img src="https://raw.githubusercontent.com/NotSaam/FLK0S-Ecosystem/main/screenshots/hub-overview.png" alt="FLK0S — Centro de Operaciones" width="100%"/>
</a>

> Un ecosistema de **6 servicios** (Hub + Auth Gateway + 4 módulos) diseñado y desarrollado end-to-end:
> **SSO único + MFA + RBAC**, multi-tenant, ticketing unificado, datos en vivo y observabilidad e2e.
> **Stack:** Next.js 14 · FastAPI · PostgreSQL · Docker · OpenTelemetry.
